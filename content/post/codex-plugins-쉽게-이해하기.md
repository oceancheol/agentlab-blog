`Codex Plugins`는 한마디로 말하면 **자주 쓰는 워크플로우를 묶어서 재사용 가능한 플러그인으로 만드는 기능**이야.

AI 에이전트를 프로젝트마다 매번 새로 세팅하면 번거롭잖아. Codex Plugins는 그런 설정을 하나의 패키지처럼 묶어서, 다른 프로젝트나 팀에서도 비슷하게 쓸 수 있게 해줘.

## 왜 필요한가

AI 작업을 하다 보면 같은 패턴이 자주 반복돼.

- 같은 프롬프트를 계속 다시 쓰기
- 같은 앱 연동을 여러 프로젝트에 복붙하기
- 같은 MCP 서버 설정을 매번 다시 만들기
- 팀마다 비슷한 에이전트 구성을 따로 관리하기

Plugins는 이런 걸 줄이기 위한 장치야. 즉, **에이전트용 템플릿 번들** 같은 느낌으로 보면 돼.

## 무엇을 담을 수 있나

Codex 문서에 따르면 플러그인에는 크게 이런 것들이 들어갈 수 있어.

- Skills: Codex가 읽는 워크플로우 프롬프트
- Apps: 앱 연동이나 커넥터 설정
- MCP servers: 원격 도구나 공유 컨텍스트

쉽게 말하면, 플러그인 하나에 “어떻게 일할지”와 “어떤 도구를 쓸지”를 같이 넣는 거야.

## 플러그인 구조

플러그인은 보통 이런 구조로 돼 있어.

- `.codex-plugin/plugin.json` : 필수 매니페스트
- `skills/` : 재사용 가능한 스킬 폴더
- `.app.json` : 앱 또는 커넥터 정의
- `.mcp.json` : MCP 서버 설정
- `assets/` : 아이콘, 스크린샷 같은 시각 자료

핵심은 `plugin.json`이 출입문 역할을 하고, 나머지는 그 안에 들어가는 구성요소라는 점이야.

## 초보자 기준으로 보면

가장 쉬운 비유는 이거야.

- **스킬** = 사용 설명서
- **앱 설정** = 연결된 도구 목록
- **MCP 서버** = 외부 작업 공간
- **플러그인** = 이 모든 걸 한 번에 묶은 상자

즉, 플러그인을 설치하면 Codex가 그 상자를 열어서 필요한 설정과 워크플로우를 함께 가져가는 거야.

## 어디서 쓰는가

문서 기준으로는 두 가지 방식이 있어.

### Codex 앱

OpenAI가 큐레이션한 플러그인은 Codex 디렉터리에서 볼 수 있어.

### Codex CLI

CLI에서는 `codex` 실행 후 `/plugins`로 플러그인 화면을 열 수 있어.

## 로컬에서 쓰는 방법

가장 현실적인 시작은 로컬 플러그인이야.

문서에서는 다음 두 가지를 권장해.

- 빠르게 시작하려면 `@plugin-creator` 스킬로 새 플러그인 만들기
- 이미 만든 플러그인이 있으면 로컬 마켓플레이스에 추가하기

로컬 마켓플레이스는 저장소 안의 `.agents/plugins/marketplace.json` 같은 파일로 관리할 수 있어.

예를 들면 이런 흐름이야.

1. 플러그인 폴더를 저장소 안 `./plugins/`로 복사
2. 마켓플레이스 JSON에 그 경로를 등록
3. Codex를 다시 시작해서 인식 확인

즉, 서버에 올려야만 하는 게 아니라 **로컬에서도 충분히 테스트 가능**해.

## 매니페스트가 중요한 이유

`plugin.json`에는 플러그인의 이름, 버전, 설명, 작성자, 저장소, 라이선스 같은 정보가 들어가.

그리고 인터페이스용 메타데이터도 넣을 수 있어.

예를 들면:
- 표시 이름
- 간단 설명
- 긴 설명
- 브랜드 색상
- 로고
- 스크린샷

이건 단순 장식이 아니라, 나중에 팀이 플러그인을 고를 때 중요한 기준이 돼.

## 언제 플러그인을 만들면 좋을까

문서가 말하는 기준을 쉽게 풀면 이래.

- 한 저장소 안에서만 쓸 거면 스킬로 충분할 때
- 여러 프로젝트나 팀 전체에서 같이 쓸 거면 플러그인이 더 좋을 때
- MCP 설정, 앱 연동, 스킬을 함께 배포하고 싶을 때
- 버전 관리 가능한 단위로 묶고 싶을 때

즉, **처음엔 로컬 스킬로 시작하고, 재사용이 필요해지면 플러그인으로 패키징**하면 돼.

## 한 줄로 정리하면

Codex Plugins는 AI 작업에 필요한 스킬, 앱 연동, MCP 설정을 한 번에 묶어 재사용할 수 있게 해주는 패키지야.

프로젝트마다 흩어진 설정을 정리하고 싶을 때 특히 유용해.

## 핵심 요약

- 플러그인은 재사용 가능한 AI 워크플로우 묶음이야
- 스킬, 앱, MCP 서버를 함께 담을 수 있어
- `.codex-plugin/plugin.json`이 필수야
- 로컬 마켓플레이스에서 먼저 테스트할 수 있어
- 팀 공유나 표준화에 잘 맞아
