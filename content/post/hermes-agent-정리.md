## 한줄 요약

Hermes Agent는 단순한 챗봇이 아니라, **기억·도구·스킬·메시징·크론**을 한데 묶은 대화형 에이전트 프레임워크다.  
핵심은 “대화”가 아니라 **대화를 통해 스스로를 계속 개선하는 구조**에 있다.

## 왜 눈에 띄나

보통 에이전트 도구는 모델 호출, 툴 실행, 세션 관리 정도에서 끝난다.  
그런데 Hermes Agent는 한 단계 더 나간다.

- 세션 간 기억을 이어 붙이고
- 사용 경험을 바탕으로 스킬을 만들고
- 필요하면 학습 루프를 돌리고
- 텔레그램, 디스코드, 슬랙, 왓츠앱, 시그널, CLI까지 한 흐름으로 묶는다

즉, “모델을 실행하는 도구”라기보다 **계속 자라는 개인용 에이전트 운영체제**에 가깝다.

## 핵심 기능

### 1) 자기개선 루프

Hermes Agent의 가장 큰 특징은 **built-in learning loop**다.

- 경험을 바탕으로 스킬을 생성한다
- 사용하면서 스킬을 다듬는다
- 오래된 대화와 기억을 다시 검색한다
- 사용자에 대한 모델을 세션을 넘어 누적한다

이 구조 덕분에 같은 일을 반복할수록 에이전트가 점점 더 유용해질 수 있다.

### 2) 기억과 회상

이 저장소는 단순히 “현재 대화만 잘하는 에이전트”를 목표로 하지 않는다.  
오히려 **이전 세션의 대화, 메모리, 사용자 프로필**을 활용해 맥락을 이어간다.

이건 꽤 중요하다.  
에이전트가 똑똑해 보이는 순간은 답변이 길고 화려할 때가 아니라, **이전 맥락을 잊지 않을 때**다.

### 3) 스킬 시스템

Hermes는 작업 경험을 스킬 형태로 축적하는 방향을 강조한다.

- 자주 하는 작업을 스킬로 정리
- 필요한 순간에 불러오기
- 사용 중 개선
- 스킬 허브와 연계

이 방식은 결국 “매번 처음부터 설명해야 하는 비용”을 줄여준다.

### 4) 메시징 게이트웨이

CLI만 있는 게 아니다.  
Telegram, Discord, Slack, WhatsApp, Signal, Email 같은 채널에서 같은 에이전트를 쓸 수 있다.

이건 실제 사용에서 꽤 큰 차이를 만든다.

- 집에서는 CLI로 쓰고
- 밖에서는 텔레그램으로 부르고
- 같은 기억과 설정을 이어받는다

에이전트가 **앱이 아니라 존재감**처럼 느껴지는 지점이다.

### 5) 크론과 자동화

Hermes는 스케줄 작업도 품고 있다.

- 일일 보고
- 야간 백업
- 주간 점검
- 자연어 기반 자동화

에이전트를 “대화 상대”가 아니라 **정기적으로 일을 처리하는 실행 주체**로 쓰려는 의도가 분명하다.

### 6) 병렬 작업과 서브에이전트

복잡한 작업을 나눠 처리하는 구조도 있다.

- 서브에이전트를 따로 띄우고
- 작업을 병렬화하고
- 결과를 다시 합치는 흐름

이건 큰 작업에서 특히 유용하다.  
문서 정리, 리서치, 코드 분석처럼 단계가 많은 일일수록 효과가 크다.

## 설치와 진입점

공식 문서 기준으로 Hermes는 Linux, macOS, WSL2에서 동작하고, 설치 스크립트로 빠르게 시작할 수 있다.

대표 진입점은 두 가지다.

- `hermes` : 터미널 대화 인터페이스
- `hermes gateway` : 메시징 채널 연결용 게이트웨이

자주 쓰는 명령도 꽤 직관적이다.

- `hermes model` : 모델 변경
- `hermes tools` : 도구 설정
- `hermes setup` : 전체 설정 마법사
- `hermes claw migrate` : OpenClaw에서 마이그레이션
- `hermes doctor` : 문제 진단

## OpenClaw와의 관계

이 저장소 설명에서 눈에 띈 부분은 **OpenClaw에서의 설정, 메모리, 스킬, 키 등을 가져올 수 있다**는 점이다.

즉, Hermes Agent는 완전히 새로 시작하는 프로젝트라기보다,  
기존 에이전트 사용 경험을 흡수해서 확장하려는 흐름에 가깝다.

이런 구조는 이전 도구에서 쌓은 자산을 버리지 않게 해준다.  
실무적으로도 꽤 중요한 장점이다.

## 장점

- 기억과 스킬이 분리돼 있어 구조가 명확하다
- 메시징 채널과 CLI를 같이 지원해 접근성이 좋다
- 자동화와 스케줄링이 내장돼 있다
- OpenClaw 마이그레이션 경로가 있다
- 다양한 모델 공급자를 지원해 락인이 적다

## 아쉬운 점

- 기능이 많아서 처음엔 복잡해 보일 수 있다
- “무엇을 어디서 설정해야 하는지” 익숙해지기까지 시간이 든다
- 이런 계열 도구는 결국 설정 품질이 사용성을 좌우한다

즉, 강력하지만 가볍게 보기 어려운 도구다.

## 이런 사람에게 맞는다

- 에이전트를 단순 챗봇이 아니라 운영 도구로 쓰고 싶은 사람
- 세션 간 기억과 스킬 축적을 중요하게 보는 사람
- CLI와 메신저를 오가며 같은 에이전트를 쓰고 싶은 사람
- 자동화와 서브에이전트 병렬화를 적극적으로 활용하고 싶은 사람

## 마무리

Hermes Agent는 “대화 잘하는 봇”을 넘어서, **사용 경험이 쌓일수록 더 유용해지는 에이전트 환경**을 지향한다.  
기억, 스킬, 메시징, 자동화, 병렬 실행이 서로 따로 놀지 않고 하나의 흐름으로 묶인 점이 가장 인상적이다.

에이전트를 오래 써볼 생각이라면, 이런 방향은 꽤 설득력 있다.

## 메타 설명

Hermes Agent는 기억, 스킬, 메시징, 크론, 서브에이전트를 묶어 스스로 성장하는 대화형 에이전트 프레임워크다. 핵심 기능과 활용 포인트를 블로그용으로 정리했다.
