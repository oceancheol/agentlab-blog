## 한줄 요약

Gemma Gem은 **브라우저 안에서 직접 동작하는 개인 AI 에이전트**다.  
클라우드 API가 아니라 **WebGPU로 온디바이스 추론**을 돌리고, 페이지를 읽고 클릭하고 입력까지 할 수 있다.

## 왜 눈에 띄나

대부분의 에이전트는 서버에서 모델을 돌린다.  
하지만 Gemma Gem은 방향이 다르다.

- API 키가 필요 없다
- 클라우드로 데이터를 보내지 않는다
- 내 브라우저 안에서 바로 움직인다
- 웹페이지를 읽고, 누르고, 입력하고, 자바스크립트까지 실행한다

즉, 이건 “채팅만 하는 모델”이 아니라 **웹 작업을 수행하는 브라우저 내 에이전트**다.

## 구조 한눈에 보기

Gemma Gem의 핵심은 간단하다.  
모델은 브라우저 내부에서 돌고, 메시지 라우터가 중간을 연결하고, 콘텐츠 스크립트가 실제 페이지에 손을 댄다.

## 동작 방식

Gemma Gem은 대략 세 부분으로 나뉜다.

### 1) 오프스크린 문서

여기서 Gemma 4 모델이 WebGPU로 실행된다.  
즉, 실제 추론은 브라우저 탭 밖의 오프스크린 문서에서 처리된다.

### 2) 서비스 워커

서비스 워커는 메시지 전달과 일부 도구 실행을 맡는다.  
스크린샷을 찍거나 자바스크립트를 실행하는 역할도 여기서 이어진다.

### 3) 콘텐츠 스크립트

콘텐츠 스크립트는 웹페이지에 주입된다.  
여기서 페이지 내용을 읽고, 버튼을 클릭하고, 입력하고, 스크롤한다.

이 구조 덕분에 에이전트가 단순한 요약기가 아니라 **실제 웹 조작 주체**가 된다.

## 가능한 도구들

Gemma Gem이 지원하는 대표 도구는 이런 것들이다.

- `read_page_content` : 페이지나 선택자 내용을 읽기
- `take_screenshot` : 현재 화면 캡처
- `click_element` : CSS 선택자로 클릭
- `type_text` : 입력창에 타이핑
- `scroll_page` : 스크롤 이동
- `run_javascript` : 페이지 문맥에서 JS 실행

이걸 합치면 꽤 많은 작업이 된다.

- 문서 요약
- 폼 자동 입력
- 페이지 버튼 조작
- 화면 기반 질문 응답
- 단순한 웹 작업 자동화

## 하드웨어와 용량

이 프로젝트는 꽤 현실적인 제약도 제시한다.

- Chrome의 WebGPU 지원 필요
- E2B 모델은 약 500MB
- E4B 모델은 약 1.5GB
- 첫 실행 뒤에는 캐시돼서 다시 쓰기 쉽다

즉, 거대한 서버 없이도 시작할 수 있지만, 그래도 **브라우저 ML과 로컬 모델 추론**의 기본 부담은 감수해야 한다.

## 설치 흐름

공식 안내는 비교적 단순하다.

- `pnpm install`
- `pnpm build`
- Chrome의 확장 프로그램 관리 화면에서 개발자 모드로 로드
- `./.output/chrome-mv3-dev/`를 불러오기

설치 후에는 웹페이지를 열고, 하단의 gem 아이콘을 눌러 대화를 시작하면 된다.

## 설정에서 중요한 점

기어 아이콘에서 다음 항목들을 조정할 수 있다.

- 모델 전환
- 사고 모드 토글
- 최대 반복 횟수
- 현재 페이지 컨텍스트 초기화
- 사이트별 비활성화

이 부분이 좋다.  
브라우저 에이전트는 늘 “얼마나 오래 생각하게 할지”, “어디까지 개입할지”가 중요하기 때문이다.

## 장점

- 데이터가 기기 밖으로 나가지 않는다는 점이 강하다
- API 키 없이 바로 쓸 수 있다
- 웹 페이지 조작이 내장돼 있다
- 브라우저 안에서 바로 동작해 진입이 가볍다
- 확장 구조가 비교적 명확하다

## 아쉬운 점

- WebGPU와 브라우저 환경 제약을 탄다
- 로컬 모델 특성상 성능이 기기 영향을 많이 받는다
- 복잡한 장기 작업에는 한계가 있을 수 있다

즉, 만능은 아니지만 **로컬 중심 에이전트**로는 매력적이다.

## 이런 사람에게 맞는다

- 브라우저 안에서 바로 움직이는 에이전트를 보고 싶은 사람
- 클라우드 전송 없이 로컬에서 처리하고 싶은 사람
- 웹 자동화와 LLM을 한 덩어리로 쓰고 싶은 사람
- 확장 프로그램 형태의 AI 에이전트를 탐색하는 사람

## 마무리

Gemma Gem은 “브라우저에 붙은 챗봇”이 아니라, **브라우저 내부에서 추론하고 행동하는 에이전트**에 가깝다.  
온디바이스 추론, 페이지 조작, 자바스크립트 실행이 한 구조 안에 들어 있다는 점이 핵심이다.

웹에서 바로 쓰는 개인 AI 비서가 어떤 모습일지 보고 싶다면, 꽤 흥미로운 프로젝트다.

## 메타 설명

Gemma Gem은 WebGPU를 이용해 브라우저 안에서 Gemma 4를 직접 실행하는 개인 AI 에이전트다. 페이지 읽기, 클릭, 입력, 자바스크립트 실행까지 가능한 구조를 정리했다.
